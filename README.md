## 📖 Tentang Proyek Ini
**Personal Finance & Expense Tracker** adalah aplikasi web berbasis front-end yang dirancang untuk membantu pengguna mencatat, mengelola, dan memantau keuangan pribadi mereka secara langsung di browser. 

Proyek ini merupakan **Proyek Akhir (Submission)** dari kelas **Belajar Membuat Front-End Web untuk Pemula** di [Dicoding Indonesia](https://www.dicoding.com/). Aplikasi ini dibangun sepenuhnya menggunakan **Vanilla JavaScript (Murni)** tanpa bantuan framework atau library eksternal seperti React/Vue, dengan menerapkan konsep *DOM Manipulation*, *Web Storage API*, dan *Custom Events*.

## ✨ Fitur Utama (Bintang 5 / Advanced ⭐⭐⭐⭐⭐)
- ✅ **Dashboard Dinamis:** Ringkasan Saldo, Total Pemasukan, dan Total Pengeluaran terupdate secara otomatis dan *real-time*.
- ✅ **Manajemen Transaksi (CRUD):** Tambah, Edit, Hapus, dan Ubah Tipe transaksi (Pemasukan <-> Pengeluaran) dengan mudah.
- ✅ **Penyimpanan Lokal (Web Storage):** Data tersimpan aman di `localStorage` browser sehingga tidak akan hilang meskipun halaman di-*refresh*.
- ✅ **Pencarian Real-time:** Filter riwayat transaksi berdasarkan judul secara instan saat pengguna mengetik.
- ✅ **Validasi Form Cerdas:** Mencegah input data kosong atau nominal yang tidak valid dengan peringatan otomatis.
- ✅ **Custom Events Architecture:** Menggunakan `CustomEvent` untuk memisahkan logika pemrosesan data dan pembaruan UI, membuat kode lebih rapi dan terstruktur.

## 🚀 Cara Menjalankan Aplikasi
Karena ini adalah aplikasi web statis (Vanilla JS), kamu tidak perlu melakukan instalasi *server* atau *package manager* yang rumit.

1. **Clone atau Download** repository ini ke komputer kamu.
2. Buka folder proyek.
3. Klik dua kali pada file **`index.html`** (atau buka menggunakan ekstensi *Live Server* di VSCode).
4. Aplikasi siap digunakan di browser favoritmu!

## 🛠️ Teknologi yang Digunakan
- **HTML5:** Untuk struktur semantik aplikasi.
- **CSS3:** Untuk *styling*, layout responsif (Grid & Flexbox), dan animasi transisi.
- **Vanilla JavaScript (ES6+):** Untuk logika bisnis, manipulasi DOM, dan *event handling*.
